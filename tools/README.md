# 工具脚本

这些脚本从冻结数据和结果生成报告或图表，不负责运行正式检索。

| 脚本 | 输出 |
|---|---|
| `create_dataset_overview_image.py` | `docs/assets/最终数据集结构图.{png,svg}` |
| `create_dataset_report_docx.py` | `docs/reports/最终数据集设定与构建说明.docx` |
| `create_baseline_report_docx.py` | `docs/reports/冻结基线实验设计与结果分析报告.docx` |
| `create_router_agent_report.py` | `docs/reports/router_and_agent_design_and_results.docx` |
| `create_final_project_report.py` | `docs/reports/最终项目报告_轻量级多索引智能体搜索.docx` |
| `generate_agent_visualizations.py` | `figures/agent/` |

所有命令都应从仓库根目录执行。
